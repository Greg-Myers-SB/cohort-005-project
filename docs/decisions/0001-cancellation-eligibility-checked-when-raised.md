# Cancellation eligibility is checked only when it is raised

A Cancellation's eligibility (Cancellation window, watch time, lesson completion, unclaimed Seat) is checked once, when it is raised. The course is not locked while the Cancellation waits for an Admin, so a learner can keep watching. If they do, the Admin can take that into account and decline. We chose this over re-checking at approval time or locking the course, to keep the software simple and leave the judgement with a person. Instructor-facing documentation needs to explain this.
